Keyboard shortcuts

1 – 9
Show that numbered block on the active half
[   ]
Previous / next block on the active half
Tab
Switch the active half, from a half's rows
S
Swap the two sides
N
Add a block and start editing it
E
Edit the active half's headers, at the pinned row's line if a row is pinned
M
Jump to the active half's notes
F2
Rename the selected block
Delete
Remove the selected block
W
Toggle word wrapping
L
Toggle line numbers
D
Toggle downcasing
H
Toggle difference highlighting
,
Open settings
?
Show or hide this list
Esc
Close the edit area, settings, or this list; on a block with no headers it deletes the block, asking first if the block has a note

The active half is the one you last clicked; an accent line marks its menu bar. Hovering a row lights its counterpart in the other half; clicking pins the pair until you click it again or press Esc. Shortcuts pause while you are typing in a field.
